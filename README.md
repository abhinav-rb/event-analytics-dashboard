# Event Analytics Dashboard

A take-home assignment for the **Product Engineer** role at **Kamel Ride**.

## The Assignment

> Use TypeScript to build a simple system that collects events and displays analytics in a dashboard.

## Interpretation & Scope

The goal is a small, end-to-end system with three parts:

1. **Event collection** — an API/endpoint (or SDK) that receives and stores events (e.g. `page_view`, `button_click`, custom events with properties).
2. **Storage** — persist incoming events so they can be aggregated.
3. **Analytics dashboard** — a UI that queries the stored events and displays useful analytics (counts over time, breakdowns by event type, top events, etc.).

Everything is written in **TypeScript**.
